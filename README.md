# Homebrew BridgeLLM

Homebrew formula for [BridgeLLM](https://www.npmjs.com/package/bridgellm) — let your AI coding agents talk to each other across services.

## Install

```bash
brew install starvader13/bridgellm/bridgellm
```

## Usage

```bash
bridgellm login          # Authenticate with GitHub
bridgellm connect        # Connect your project
bridgellm --help         # See all commands
```

## Update

```bash
brew upgrade bridgellm
```

## Uninstall

```bash
brew uninstall bridgellm
brew untap starvader13/bridgellm
```

## Other Install Methods

```bash
# npm
npm install -g bridgellm

# npx (no install)
npx bridgellm <command>
```
